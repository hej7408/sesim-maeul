# 세심마을 — 4학년 「함께하는 세심교실」 체험형 웹앱

한국조세재정연구원 「함께하는 세심교실」(2026) 10차시 교재·PPT·활동지·워크북·반응형 웹 안내서·세금통 게임 설명서를 바탕으로 만든
**초등 4학년용 체험 중심 웹앱**입니다. 설치·빌드·서버 없이 `index.html`을 여는 정적 웹앱이고, 모든 기록은 학생 기기의 브라우저(localStorage)에만 저장됩니다.

## 실행

| 방법 | 설명 |
|---|---|
| 권장 | 이 폴더에서 `python serve.py` → 브라우저에서 `http://localhost:5230` |
| 학교 PC | `index.html` 더블클릭도 대부분 동작(글꼴 Jua만 인터넷 필요, 없으면 맑은 고딕) |
| 태블릿·크롬북 | 위 폴더를 교내 웹서버/Google Sites/GitHub Pages 등에 그대로 올리면 PC·태블릿·모바일에서 동작(반응형) |

## 4학년 눈높이 설명 (2차 보강)
- **📘 개념 배우기**: 모든 차시의 첫 활동. 그림·흐름도·비교 카드·쉬운 비유(학급 회비, 용돈기입장 등)로 6장씩 설명하고, 확인 문제 2개로 마무리해요. 활동 중에도 `📘 개념 다시 보기` 버튼으로 언제든 열 수 있어요.
- **밑줄 친 낱말**을 누르면 뜻이 바로 나오고, **📖 용어사전**(`#/words`)에서 60여 개 낱말을 검색할 수 있어요.
- **디자인**: 마을 풍경 배경(`img/bg-village.svg`), 차시별 색·무늬 헤더, 구불구불 차시 길, 3D 버튼, 번호표 달린 퀴즈 보기.

## 구성 (교재 흐름 그대로)

학생은 **마을 이장님**이 되어 직업을 얻고 월급을 받으며(소득세 원천징수), 활동마다 세금을 직접 내고 쓰고 정하면서 세금을 체험합니다.

| 차시 | 주제 | 체험 활동 |
|---|---|---|
| 0 | 입주 | 신분증·마을 이름·캐릭터·직업·마을 규칙·서명, 환영 선물 |
| 1 | 세금이 필요해 | 공공시설 지도 탐험, 세금 브이로그, 내 것/우리 모두의 것, 세금 OFF 실험, 보물상자에 세금 내기(3:1), 석송령·OX |
| 2 | 세금을 어떻게 정할까 | 왕 시뮬레이션, 세법 속 숨은 세금 찾기·수정, 세심회의→세법전→첫 세금 납부(납부확인증), 세종대왕 공법, 초성 퀴즈 |
| 3 | 공평한 세금 | 울타리 상자 나누기, 정액세·비례세·누진세 계산기(A 9,500만/B 500만), 직업별 세율 설계(공평 점수), 소득재분배, 공평 사례 |
| 4 | 세금은 어디에 | 분야 분류, 예산 편성 순서, 예산안 짜기(국회 심의), 짝 맞추기·몸으로 말해요, **세금통 카드게임**, 국세·지방세/보통세·목적세, 2027 예산 |
| 5 | 물건 살 때 세금 | 마트 영수증(부가가치세), 시장에서 실제 구매, 설탕세·탄소세 실험(교정적 조세), 환경세 이름 맞히기, 세금 제안서 |
| 6 | 회사도 세금 | 법인 개념 토론, 돈의 흐름(법인세→배당소득세·근로소득세), **가게 창업 시뮬**(사업보고서), 세제 혜택 |
| 7 | 집을 살 때·가질 때 | 무택이 이야기, 내 재산 마련(취득세·재산세·양도소득세), 세율 계산, **세금왕 게임** |
| 8 | 탈세와 절세 | 탈세/절세 분류, **세금공무원 게임**, 정직한 세금이 진짜 보물이야(이야기·인터뷰), 세금 히어로, 성실납세 서약(서명) |
| 9 | 결산 | 결산 개념, 세금 더 걷힐까, 내 세금 결산서·세금내역서 분류, 나라 살림·빚 시뮬, 복습 퀴즈 |
| 10 | 진짜 세금 세상 | 세금의 역사(조용조·공법·국세청·금융실명제), 이런 세금 진짜?, 오줌세·창문세, 로봇세·미래의 세금, 세금 낭비, 그림일기·수료증 |

### 마을 곳곳 (원본 반응형 웹의 은행·국세청·시장·세법전을 4학년 눈높이로)
- 🏦 **세심은행** 지갑, 거래내역, 일반/세금우대 저축(절세 체험) · 🛒 **시장** 부가가치세 영수증 · 🏛️ **국세청** 내 세금 현황·납부확인증·세금으로 짓는 마을 시설
- 📜 **세법전** 학급 세법(교사 설정) + 내가 제안한 세금 · 📒 **세심기입장** 쓴 글·납부확인증·배지 · 🏅 **수료증**(인쇄 가능)
- 🎮 **놀이터** 세금통(카드/메모리), 세금왕, 세금 퀴즈왕, 세금 계산 스피드

### 교사용 (`#/teacher`, 비밀번호 설정)
학급 코드·화폐 단위, **세율(소득/부가가치/법인/배당/취득/재산)·누진 구간**, 열어 줄 차시, 입주 선물·활동 급여, 학생 현황(진도·잔액·세금), 급여 지급/범칙금 부과, CSV·JSON 백업/가져오기, 수업 안내.

## 설계 결정과 참고 (확인이 필요한 부분)
- **자료 근거**: 차시 구성·용어·사례는 제공해 주신 PPT/활동지/워크북을 따랐습니다. 워크북은 저학년 「자라나는 세심교실」 자료여서 4학년에 맞게 *보물상자 세금 3:1, 내 것/우리 것 분류, 세금 천재 OX, 동화(정직한 세금), 세금 히어로, 오줌세·창문세* 활동만 가져왔습니다.
- **세금통 카드 20종**: 설명서 이미지의 4종(환경미화원·예술의 전당·도서관·신호등) 외 16종과 **별 개수(1~3개)**, 내 손의 같은 카드 2장 자동 내려놓기는 앱에서 정했습니다.
- **세금왕 재산 카드**: 승용차·아파트 수치는 활동지 그대로, 나머지 10종은 같은 비율로 만든 값입니다. 말판 칸 구성도 활동지의 칸 종류를 재구성했습니다.
- **추가 조사 자료**(2026-10 웹 검색): 2027년 정부 예산안 분야별 규모(언론 보도 기준, 어림 자료), 세계 환경세·재미있는 세금 사례(영국 창문·모자·벽돌세, 러시아 수염세, 덴마크 가축 온실가스세, 독일 강아지세), 연분구등법 9등급 등 일반 상식 수준의 역사 사실. 수업 전 교사용 확인을 권합니다.
- **캐릭터 이미지**(세심이 등)는 제공 자료에서 추출한 것이라 **교내 수업용**으로만 쓰고 외부 공개 배포는 피해 주세요.
- **경제 수치**(월급 450~900심, 활동 급여 50심, 시장 가격 등)는 4학년이 한 학기 동안 쓸 만한 크기로 정했고, 교사 설정에서 조정할 수 있습니다.
- **마을 시설 건설**: "이 기기에 등록된 학생들의 세금 합계"로 계산합니다. 여러 기기를 쓰면 기기별로 따로 계산되므로, 합산은 교사 백업(JSON) 가져오기를 이용하세요.
- 서버가 없어 **학생끼리 실시간 공유는 안 됩니다**(모의 투표 등은 연습용으로 표시). 필요하면 Firebase 연동을 추가할 수 있습니다.
